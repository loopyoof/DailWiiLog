Daily Log - folder layout on the SD card: sd:/apps/dailylog/

  boot.elf (or boot.dol)   the app (built from the source; see project README)
  meta.xml, icon.png       Homebrew Channel listing
  font.ttf                 UI font (DejaVu Sans included; replace with any TrueType font)
  audio.ogg                background music, Ogg Vorbis, any time you like (not included)
  cdbackup.vff             optional: a play-log dump to read if NAND access fails
